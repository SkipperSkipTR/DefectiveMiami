# DefectiveMiami

Miami .sc files infected with the 3master plague. Posted for educational purposes.

## How to browse between versions

This repo has versions committed on top of each other in chronological order, so that you could easily see the changes each version provided.

You can browse commit history (or the tags) to reach these versions in the repo:
- **1.0** (1.01 has the same script)
- **1.03**
- **1.04**
- **1.04.5**
- **1.112**
